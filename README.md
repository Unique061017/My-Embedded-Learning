# 嵌入式学习与调试日志 (Embedded Debug Log)

作为一名软件技术专业的学生，我正在向嵌入式方向跨界。这里记录我实操中的真实 Bug 与解决思路。

## 日志 1：串口通信乱码问题排查
- **现象**：用 STM32 往电脑串口助手发数据，显示全是乱码（如 `xx`）。
- **排查思路**：
  1. 检查代码，确认波特率设置的是 9600。
  2. 检查硬件，发现晶振频率配置错误，导致实际时钟与预期不符。
- **解决**：修改了时钟树的配置，重新编译烧录，输出恢复正常。
- **收获**：底层开发不能只看代码，硬件配置（时钟、引脚）同样致命。

## 日志 2：阅读英文 Datasheet 解决传感器数据漂移
- **现象**：温湿度传感器（DHT11）读出来的数值偶尔会突变。
- **排查思路**：国内论坛没找到确切原因，直接去查阅了原厂的英文 Datasheet。
- **解决**：英文原版手册中提示，传感器上电后需要 1 秒的稳定时间。我在代码中加入了 `Delay_ms(1000)`，数据恢复正常。
- **收获**：英语好真的能提高排错效率，原版文档才是第一手资料。
